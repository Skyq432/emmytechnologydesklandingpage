# Emmy Technology Foldable Desk Landing Page

Sony-inspired premium product landing page for `desk.emmytechnology.com`.

## Brand system
- Primary: `#032489`
- Secondary: `#ffb100`
- Body/navigation: **Inter**
- Hero and section headings: **Plus Jakarta Sans**

## Start locally
Double-click `START_HERE.bat`, or run:

```powershell
npm run dev
```

Then open `http://localhost:5173`.
